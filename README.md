# HR Data Analysis

## 📊 Project Overview

An interactive Power BI dashboard designed to analyze employee data and identify workforce patterns and HR-related insights.

The project focuses on understanding employee demographics, workforce distribution, and key HR metrics through interactive data visualization.

## 📈 Dashboard Analysis

- Employee workforce analysis
- Department-wise employee distribution
- Employee demographic analysis
- Workforce trends and patterns
- HR metric analysis
- Interactive filtering and visual exploration

## 🛠️ Tools & Technologies
